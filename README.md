# Nexus AI

Project scaffold for a document-aware AI tutoring application.

## Structure

- `backend/`: API, services, models, and database modules
- `frontend/`: application entry point
- `data/uploads/`: uploaded documents (ignored by Git)
- `data/chroma/`: local vector store data (ignored by Git)
- `tests/`: automated tests

Add project dependencies to `requirements.txt` and local configuration to `.env`.
